# 04. 評価ループ（のりプロで精度を上げ、ホロライブで本番）

「1本作る → 見て評価する → 伸びている切り抜きと比べて何がダメかまとめる → 直す」を回すための手順。

## 対象

| タレント | 配信の特徴 | このループで鍛える力 |
|---|---|---|
| レグルシュ・ライオンハート | ゲーム実況（ホラー等）・雑談・食レポ。リアクション型 | 叫び・笑いの検出、ゲーム音（BGM/SE）に惑わされない |
| 斎木こまり | 雑談・お絵描き・作業配信。トーク型 | 静かな会話から面白い所を拾う、切り抜く所が無い配信では何も出さない |

最初は**単独配信**で行う（コラボは相手の事務所ルールが加わるため）。

## 1周の手順

```bash
# 0) 素材の取得（YouTube に繋がる環境で）
kirinuki refs <伸びている切り抜きのURL...> -o refs/       # 動画 + 再生数・タイトル(info.json)
#   元配信は run に URL を渡せば動画・チャット・字幕・メタデータをまとめて取得する

# 1) 1本作る
kirinuki run "<元配信のURL>" -p noripro -o out/

# 2) 正解データ: 伸びている切り抜きが元配信のどこかを音声で特定
kirinuki truth out/source/source.mp4 refs/*.mp4 -o truth.json

# 3) 採点: AIの選んだ区間が人間の切り抜きと一致したか
kirinuki eval out/report.json truth.json        # recall@k, 再生数で重み付けした recall, 逃した区間

# 4) 見た目の評価: コマ割り画像 + 指標を、伸びている切り抜きと比較
kirinuki review out/clip_01.mp4 --ref refs/*.mp4 -o review/
```

`review/` にできるもの:
- `clip_01_sheet.jpg` … 上段: 冒頭3秒(0.5秒刻み)、下段: 全体12コマ（時刻付き）
- `clip_01_review.md` … 尺・カット頻度・発話率・最長の沈黙・音量・冒頭の勢い・字幕密度・タイトル長を参照の中央値と比較し、外れていれば ⚠️
- `ref_*_sheet.jpg` … 伸びている切り抜きのコマ割り（並べて見比べる用）

## レビューの観点（毎回 docs/05 に記録する）

1. **選んだ場所**: 人間の伸びた切り抜きと一致したか / 逃した山場は何で、なぜ逃したか（音量・笑い語・チャットのどれが弱かったか）
2. **境界**: 文の途中から始まっていないか / オチの後の余韻 / 前フリの長さ
3. **冒頭3秒**: 何の動画か分かるか、続きを見たくなるか（参照の冒頭と見比べる）
4. **テンポ**: カット頻度・沈黙が参照と比べてどうか
5. **テロップ**: 量・速さ・位置・強調の使い方を参照と比べる
6. **タイトル・サムネ**: 参照の伸びたタイトルの型と比べる。誇張になっていないか

## 合格ライン（暫定）

| 指標 | 目標 |
|---|---|
| recall@5（人間の伸びた切り抜きの区間を上位5本で拾えた割合） | 0.6 以上 |
| 再生数で重み付けした recall@5 | 0.7 以上 |
| 目視チェック 8項目 | 7項目以上 ✅ |
| 斎木こまりさんの作業配信（無言） | 出力 0〜1本 |

合格したらホロライブの配信で同じ設定のまま測り、精度が落ちないことを確認してから本番に移る。
