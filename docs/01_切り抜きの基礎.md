# 01. 切り抜き動画の基礎 ― 何が必要で、どう作り、どう編集するか

最強の切り抜きAIを作る前に、「人間の上手い切り抜き師が何をしているか」を分解する。
AIはこの工程を1つずつ置き換えていく。

---

## 1. 必要なもの

| 分類 | 必要なもの | 補足 |
|---|---|---|
| 素材 | 元動画（配信アーカイブ・対談・実況など） | 長尺ほど「探す」コストが大きく、AI化の効果も大きい |
| 権利 | 配信者の切り抜きガイドラインの確認 | 許可制/収益化可否/クレジット表記/NG内容（BGM・ゲーム映像など）はチャンネルごとに違う |
| 道具 | 動画編集（ffmpeg / Premiere / DaVinci / CapCut） | 本プロジェクトは ffmpeg で自動化 |
| 道具 | 文字起こし（Whisper系） | 字幕と「何を話しているか」の把握の両方に使う |
| 道具 | フォント | 太くて読みやすい日本語フォント（ゴシック系）＋縁取り |
| 知識 | 元配信の文脈、内輪ネタ、登場人物 | 文脈なしで伝わるかの判断に必須 |

## 2. 上手い切り抜きの条件（良い切り抜き = この5つ）

1. **冒頭1〜3秒で掴む（フック）**
   自己紹介や前置きから入らない。結論・一番強い一言・リアクションを先頭に置く。
   「何の動画か」と「続きを見る理由」を1秒で伝える。
2. **単体で成立する（文脈の再構築）**
   元配信を見ていない人でも分かる。必要な前提はタイトル/テロップで補う。
3. **起承転結の「転」と「オチ」がある**
   盛り上がり（笑い・叫び・驚き）で終わる。オチの後のリアクションを0.5〜1.5秒残す。
4. **無駄な間がない（テンポ）**
   0.5秒以上の沈黙や言い淀みはジャンプカットで詰める。
5. **テロップで要点が分かる**
   音なし視聴でも内容が分かる。強調語は色を変える。一画面一情報。

## 3. 作業手順（人間の切り抜き師のワークフロー）

```
① 元動画を選ぶ        ── ガイドライン確認、伸びている配信を選ぶ
② 見どころを探す      ── コメント量・チャット「草」・声量が跳ねた所を探す（最も時間がかかる）
③ 範囲を決める        ── 「どこから始めれば単体で分かるか」「どこで切ればオチが立つか」
④ 粗編集              ── 切り出し、無駄な間のカット
⑤ 構成の調整          ── 必要ならオチの一部を冒頭に「チラ見せ」(ティーザー)
⑥ 画面作り            ── 縦型(9:16)に変換：顔/画面を中央、背景はぼかし
⑦ テロップ            ── 字幕（話者の言葉）＋強調語の色付け＋タイトル帯
⑧ 音                  ── 音量を揃える（ラウドネス正規化 -14 LUFS 目安）、必要ならSE/BGM
⑨ タイトル・サムネ    ── 何が起きたか＋感情（「〇〇が△△してしまう」型など）
⑩ 書き出し・投稿      ── クレジット表記、元動画URL、タグ
```

## 4. 編集の具体的なルール（本プロジェクトの初期値）

| 項目 | ルール | 初期値 |
|---|---|---|
| 尺（ショート） | 1ネタ完結。長すぎると離脱 | 15〜60秒（目標30〜45秒） |
| 開始点 | 文の頭から。直前の沈黙に合わせる | 文頭 −0.15秒 |
| 終了点 | オチ＋リアクションの余韻 | オチ後 +0.8秒、沈黙に吸着 |
| ジャンプカット | 長い沈黙を詰める | 0.6秒以上の沈黙を0.15秒に圧縮 |
| 画面 | 縦型 1080x1920 | 中央に元映像、上下はぼかし背景 |
| 字幕 | 1行最大14文字・2行まで、太字・黒縁 | 強調語は黄色 |
| タイトル帯 | 画面上部に常時表示 | 最大18文字程度 |
| 音量 | ラウドネス正規化 | -14 LUFS / TP -1.5 dB |
| フック | 冒頭に一番強い一言 | 必要時のみ最大3秒のティーザー |

## 5. ジャンル別の「盛り上がり」の正体

| ジャンル | 盛り上がりのサイン | 効くフック |
|---|---|---|
| ゲーム実況 | 叫び、急な音量上昇、「やばい」「うそでしょ」 | 直前の状況＋リアクション映像 |
| 雑談・トーク | 笑い（「草」「w」「笑」）、ツッコミ、暴露 | 結論・衝撃の一言をテロップで |
| 対談・ポッドキャスト | 強い主張、意外な数字、名言 | 主張を一文で先出し |
| 歌・ASMR等 | 曲のサビ、拍手 | サビ頭 |

## 6. よくある失敗

- 前置きから始まって最初の3秒で離脱される
- オチの直後でブツ切り → 余韻がなく笑えない
- 文の途中から始まる → 何の話か分からない
- 内輪ネタを説明なしで出す
- 字幕が長すぎて読めない／画面を覆う
- 権利確認をしない（最悪チャンネルごと消える）
